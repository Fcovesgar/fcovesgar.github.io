MueblesInk

Descripción

Página web de una tienda de mobiliario enfocada en la exploración y adquisición de productos. Incluye un sistema de filtros avanzado para facilitar la búsqueda, páginas de detalle de cada producto, un carrito de compras para gestionar pedidos de manera eficiente y una sección de contacto para atención al cliente.

Especificaciones Técnicas

  • Lenguajes: HTML5, CSS3, JavaScript
  • Frameworks / Librerías: Astro, Shoelace
  • Herramientas: Figma, npm, Git
  • Arquitectura / Base de datos: Firebase
  • Servicios externos: Cloudinary (almacenamiento de imágenes en la nube)
